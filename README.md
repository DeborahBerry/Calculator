# 🧮 Calculator

A functional calculator built with **Vanilla JavaScript**, HTML, and CSS. 
This project performs basic arithmetic operations including addition, subtraction, multiplication, and division. It also demonstrates a solid understanding of JavaScript fundamentals and DOM manipulation.

## 🎯 Purpose

This was built as a practice project to improve JavaScript logic, layout skills, and UI event handling. Ideal for beginners to learn from and build upon

## 🚀 Features

- Performs basic arithmetic operations (+, –, ×, ÷)
- Clean user interface
- Clear (`C`) and delete (`←`) functions
  
## 🧰 Built With

- HTML
- CSS
- JavaScript (Vanilla ES6) - (No frameworks!)

## 💬 Why This Project?

I made this to strengthen my understanding of:

- Event listeners
- Conditional logic
- DOM tree manipulation
- Clean UI structure with CSS
